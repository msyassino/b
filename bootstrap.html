🔥 الطريقة الأسهل لإضافة Admin Claim

استخدم Firebase Console Functions playground:

  1. اذهب إلى Firebase Console → Functions
  2. أنشئ function جديدة اسمها setAdmin
  3. انسخ هذا الكود:
exports.setAdmin = functions.https.onCall(async (data, context) => {
  const email = data.email;
  const role = data.role || 'super';
  
  try {
    const user = await admin.auth().getUserByEmail(email);
    await admin.auth().setCustomUserClaims(user.uid, {
      admin: true,
      adminRole: role
    });
    return { success: true, uid: user.uid };
  } catch (error) {
    return { error: error.message };
  }
});

ثم استدعِ الدالة من المتصفح بعد deploy.
